# Smart Reel & Shorts Tracker

Chrome extension to track:
- Instagram Reels watched
- YouTube Shorts watched
- Daily watch time

## Features
- Tracks reels count
- Tracks shorts count
- Tracks total watch time
- Daily statistics popup

## Technologies
- python,JavaScript
- Chrome Extension Manifest V3
- Chrome Storage API
